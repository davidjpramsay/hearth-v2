# Pocket-money design reference

The Phase 4 pocket-money replacement uses one original concept to keep the television and companion presentations visually aligned:

- `concepts/pocket-money-tv-phone.png` — Chores columns with a compact weekly percentage/amount band, and a phone-first Pocket money administration card with amount, payday and payment status.

The concept is a design reference only. It is not embedded in the product UI. The implemented interface uses Hearth components, local demo avatars, design tokens, responsive layouts and typed API data.

## Fidelity notes

- **Copy:** uses real currency, weekly progress and payment language; no stars, rewards or redemptions.
- **Composition:** weekly progress stays inside each child column on television; settings and payment recording stay in phone administration.
- **Typography/palette:** retains Source Sans 3, warm Hearth surfaces and eucalyptus progress states.
- **Focus:** television actions retain the established blue multi-cue focus treatment; administration remains keyboard/touch accessible.
- **Responsive behaviour:** the Chores board remains columnar on television and becomes a vertical child list on phone.
