# Phase 7 Photos concept

`concepts/photos-tv.png` is the accepted implementation reference for the first
Photos product slice. It was generated for Hearth from the current rendered
Today screen on 2026-08-05 and is retained only as design evidence.

The implemented screen keeps the concept's main hierarchy: one large selected
photo, a compact mixed-orientation gallery, a visible D-pad focus treatment, automatic/pause state
and a single `Start ambient` action. It deliberately uses five fictional demo
photos rather than the concept's eight because each retained asset must have a
separate display derivative, thumbnail, alternative text and orientation
record. The generated concept is never rendered inside the application.

On a phone the same typed collection remains an orientation-aware collage beneath the stable
Today/Calendar/Chores/More navigation; landscape retains only three substantial occupants. It is
not a scaled television canvas. Private mode uses the same composition with opaque local WebP
derivatives from private adult phone uploads, with one approved read-only Synology folder retained
only as an optional bulk importer.
