# Phase 5 Home concepts

These two accepted concepts were generated for Hearth with the image-generation
tool on 2026-08-03, then copied into the project before implementation. They are
design references only and are not rendered inside the product.

- `concepts/home-tv-1080-concept.png` — landscape television composition
- `concepts/home-phone-portrait-concept.png` — responsive companion hierarchy

The source prompt required the existing Hearth warm-ivory/eucalyptus/sky/ochre
language, Source Sans-style typography, Today/Week/Chores/Lists/Meals/Photos/Home
navigation, three curated household states, three actions, visible D-pad focus,
and no media controls, device browser, voice-listening UI, charts or raw entity
IDs.

The implemented interface recreates the composition with React, CSS and local
SVG icons. The generated screenshots are never shipped as interface elements.
