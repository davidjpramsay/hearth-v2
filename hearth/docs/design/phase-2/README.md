# Phase 2 setup concepts

These concepts establish the source-of-truth composition for the first
household setup slice:

- `concepts/admin-phone.png` — phone-first Home settings hierarchy
- `concepts/tv-pairing.png` — across-the-room short-code pairing surface

They extend the Phase 1 Hearth visual system with warm ivory, plum,
terracotta and sage setup states. They are reference material only; the product
is rendered from React/CSS and never embeds these screenshots as interface
elements.

Implementation adaptations are intentional: the seeded household remains
`Hearth Demo Home`, the existing Hearth mark remains authoritative, the pairing
expiry uses family-readable text rather than a ticking timer, and the TV waits
for any authenticated adult rather than naming a particular person.
